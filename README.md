# Лабораторная работа 4 — GitHub

Проект WinForms для демонстрации работы Git и GitHub, ветвления и слияния ветвей.

## Ветки
- `master` — основная версия проекта.
- `Addfunction` — отдельная ветка с дополнительной функцией тестирования.

## Команды для публикации в GitHub
```bash
git remote add origin https://github.com/USERNAME/GitHubLab4.git
git push -u origin master
git push -u origin Addfunction
```

После публикации репозитория в GitHub отображаются файлы, ветви и история коммитов.
